DEPENDENCY + EXECUTION EDITOR

依存関係・実行順序エディタ

ComfyUI方式。ノードは自動作成、接続はユーザーが手動で行う。実行は左から右へ進む。

0 CONNECTIONS
接続線には2つの意味がある： 赤（現在状態）・グレー（前回状態）の接続は ①入出力の依存関係 と ②実行順序 を同時に表す。白（実行フロー）で結ぶと、データを渡さずに実行順序だけを指定できる。
実行順序はノードの左右位置から自動決定。同じ1ステップで全機能を左→右に1回ずつ評価する。逆向き接続は禁止。グレーの接続は「前回状態」または「前回出力」を参照するための線として使える。

接続の詳細

線を接続または選択すると、その接続が渡すデータと実行順序が表示される。
● 出力ポートをドラッグして同じ種類の入力へ接続
● ノードのヘッダーで位置変更＝実行順序変更
● 接続を選択して削除可能
● グレーの接続は接続後に PREV.STATE / PREV.OUTPUT を選択できる ● 前回値は今回の1ステップでは書き換わらない
● ノードが未接続でも、左から右の順で評価される
● デモでは配線によるガード式変更は未実装。現在は接続表示と実行順序の更新を確認できる

EXECUTION ORDER

機能の逐次実行設定

依存関係エディタでの左→右のノード位置から実行順序を自動生成。後続は最新状態を参照する。

SEQUENTIAL
同じ現在状態から複数ルールが成立した場合は priority値が小さいルール を採用。同一優先度で遷移先が異なる場合は競合として報告する。
